# Arcane Hand: Horde Defense

A random-roll tower defense game for the browser. Roll towers, merge them into rarer ones, enchant them
with abilities, and hold the Verdant Vault through ten waves and a boss.

**Play:** open `index.html` in a browser, or enable GitHub Pages (see below) and play at
`https://<your-username>.github.io/<repo-name>/`.

## Project layout
| Path | What it is |
|---|---|
| `index.html` | The built game (single self-contained page). Generated by `build.py`. |
| `src/sim.js` | Deterministic game simulation (rules, waves, merging, economy). No rendering. |
| `src/game.js` | UI, input, camera, and the render loop. |
| `src/r_*.js` | Renderer modules: sky, world, grass, river and bridges, creatures, towers, effects, post-processing. |
| `src/style.css` | Interface styles. |
| `harness/` | Automated tests, balance bots, benchmarks and screenshot tools. |
| `docs/` | Design log, review rubric, credits, test results. |

## Build
Requires Python 3.
```
python3 build.py
```
This writes `index.html` (and `dist/index.html`). three.js r128 loads from cdnjs.

## Tests
Requires Node.js.
```
npm install
node --expose-gc harness/run.js tests     # rule tests
node --expose-gc harness/run.js all       # tests + balance + performance + memory
```
Screenshot tools in `harness/*.py` need `pip install playwright` and `playwright install chromium`.
